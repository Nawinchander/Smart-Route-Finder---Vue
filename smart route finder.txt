Smart Route Finder (Vue + Graph DSA)
💡 Real-life idea

A mini Google Maps–like system where a user selects:

Start location
Destination

👉 App finds shortest path using Dijkstra’s Algorithm

DSA Concept Used
Graph + Dijkstra Algorithm
Nodes = locations
Edges = roads with distance
Goal = shortest path

Used in:

Google Maps
Uber/Ola routing
Network routing (packets)
